💪 Styrka

Ditt personliga program: 3 pass/vecka · Push / Pull / Legs · nybörjarnivå · ~1 timme/pass

Så funkar programmet

  • 3 träningspass i veckan, gärna med minst 1 vilodag mellan varje pass.
  • Vila 60–120 sek mellan seten (se förslag per övning).
  • Öka vikten lite när alla set och reps känns lätta att klara ("progressiv överbelastning").
  • Bocka av set direkt i appen – allt sparas i din telefon/dator, ingenting skickas till nätet.

Byggd som en installationsbar PWA – lägg till på hemskärmen för snabb åtkomst offline.
